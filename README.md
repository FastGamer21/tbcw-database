# THE BACKSTREETS COMMONWEALTH DATABASE

## Intro
Basically, it's small project, which is related to real office "The backstreets commonwealth" (further: TBCW) in game called: "Archived" - on Roblox platform. This project containts bunch of documents, which were made by memebers of TBCW.

## Goal
I guess, make something interesting and cool for my office members and make people bond to each other even more.
Most importantly is to make lore for our office and wrap it up in interesting and cool form.

## How to add a dossier (admin)
1. Get a `TBCW-XXX.json` file from a member (generated by the HR Terminal on the site).
2. Put the file into the `dossiers/` folder.
3. Open `dossiers/manifest.json` and add the dossier id (same as filename without `.json`) on a new line.
4. Commit + push — GitHub Pages redeploys automatically in ~1 minute.

If the photo/audio are local files: put them into `img/` / `sfx/` and set relative paths
in the JSON (`img/name.png`, `sfx/name.mp3`) — **never with a leading slash** (the site
is deployed to a repository subfolder).

## How to run locally
The site is fully static — any static server works. From the repo root:
```
python -m http.server 8080
```
Then open http://127.0.0.1:8080. Opening `index.html` directly via `file://` will NOT work:
the browser blocks `fetch()` of the dossier JSON files.
